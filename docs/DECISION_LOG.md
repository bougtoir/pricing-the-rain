# Decision log

## 2026-09-24: journal route

Selected **Analysis** rather than **Methodological and Ideological Options**. The paper
uses a new integrated generative framework, but its primary claim is an analysis of an
important ecological-economic question using real-weather pseudo-interventions and
simulation. The live guide permits 8,000 words for either route.

## 2026-09-24: novelty response

Espín-Sánchez, Gil-Guirado, and Ryan's 2026 *Quarterly Journal of Economics* article
is the closest prior work and makes a simple dry-spell hazard explanation alone
non-novel. The project therefore proceeds with a modified contribution: non-monotone
empirical hazards, endogenous demand, provider acceptance, explicit plural valuation,
price formation, imperfect counterfactual observers, and reputation dynamics under an
exact zero-effect null. Any result that only repeats the rainfall-hazard mechanism is
treated as context, not as the claimed novelty.

## 2026-09-24: empirical data

Use Open-Meteo's historical archive API as a reproducible access layer for ERA5
daily precipitation at eight pre-specified point locations, 1991–2020. This is not a
claim about historical ritual sites. Locations were selected before outcome inspection
to span contrasting rainfall regimes and inhabited regions.

An initial request specifying `era5_land` returned the requested date array but all-null
precipitation. Those invalid responses are retained as an audit trail and excluded. The
validated acquisition explicitly requests `era5` and requires at least 10,800 non-null
daily values per location.

## 2026-09-24 — Preserve unfavorable simulated associations

The M4–M5 event-level price–success differences are negative on average. Parameters
will not be retuned to force the anticipated positive association. The manuscript will
distinguish a price premium generated by reputation from a positive contemporaneous
price–outcome association and report both.

## 2026-09-24: respectful scope

The study does not test actual ritual efficacy, infer historical belief, or monetise
cultural meaning. All interventions are fictional pseudo-events. Monetary quantities
are transparent model scenarios, separated from social and cultural utility.

## 2026-09-24: post-results journal positioning

Retain the *Ecological Economics* Analysis route with narrowed claims around scarcity,
selection, plural valuation, and reputation. Mark three mismatched DOI–role records
excluded and use verified replacements in manuscript drafting.

## 2026-09-24: final display architecture

Use five main figures and four main tables; keep detailed inference and sensitivity
results supplementary. Manuscript-generation code must obtain every reported number
from `results/manuscript_values.json`.

## 2026-09-24: manuscript submission architecture

Generate two manuscript versions from one numerical source. The inline-figure version
is a convenient review artifact. The submission-text version contains tables but no
embedded figures, places figure legends at the end, and is paired with separate
high-resolution figure files and an editable PPTX. References are generated in
first-appearance order from preserved metadata rather than transcribed manually.

## 2026-09-24: reproducibility architecture

The default one-command build is offline with respect to research inputs. It validates
the archived analytical weather and bibliographic metadata against machine-readable
ledgers, then rebuilds all derived analyses and submission assets in a fixed order.
Networked acquisition is an explicit optional command and never overwrites an existing
raw snapshot. Machine-readable numerical outputs receive a deterministic hash manifest;
Office and PDF containers are excluded because their internal timestamps may vary while
their generated content and source values remain unchanged.

## 2026-09-24: final statistical repair

Sparse training duration cells now fall back to training-period location-month hazards
even when a duration cell is completely absent. The WTP model includes timing-rule
fixed effects and two-way region-year/region-rule clustering. The permutation
falsification uses within-region–month–rule demeaning and shuffling plus hazard and
drought adjustment. The resulting positive price–success hypothesis is classified as
not supported rather than retuning the model.

## 2026-09-24: public synchronization and source licensing

The release branch is mapped to the public `bougtoir/pricing-the-rain` repository.
Code, archived weather, Crossref metadata, generated results, figures, tables, and
manuscript files are synchronized. The Akong'a article PDF, its landing-page snapshot,
and the captured Elsevier guide are retained in persistent private provenance storage
but excluded from public synchronization because explicit redistribution permission
was not established; exact retrieval records remain documented.
