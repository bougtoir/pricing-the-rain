# Economic Modelling compliance checklist

- [x] Article type: Research article (full-length regular paper).
- [x] Title page separate from blinded manuscript; author fields are bracketed
      placeholders pending author input (see AUTHOR_ACTIONS_REQUIRED.md).
- [x] Abstract ≤ 250 words (measured and enforced by tests/final audit).
- [x] 5 keywords supplied (journal accepts up to ~6; we use 5).
- [x] Main text ≤ 8,000 words excluding references (enforced by tests/audit).
- [x] References: author–year style, alphabetized, every entry cited in text; no
      numbered citations.
- [x] Figures 1–5 cited in order in main text; Figures S1–S3 in supplement;
      vector PDF + 600-dpi PNG provided; editable PPTX supplied.
- [x] Tables 1–4 cited in order in main text; CSV + editable DOCX supplied;
      S1–S10 in supplement.
- [x] Declarations: funding, competing interests, CRediT, ethics, data/code
      availability, generative-AI disclosure — all present with bracketed
      placeholders.
- [x] Cover letter: single-author voice, ~1 page, restrained claims, includes the
      unfavorable headline result.
- [x] No raw/restricted data inside the submission archive (audit-verified).
- [x] No mandatory APC: Economic Modelling is hybrid; OA optional.
- [ ] Author items pending: identity, affiliations, funding, CRediT,
      acknowledgements, ORCID, suggested reviewers, final submission upload
      (Elsevier Editorial Manager / EVISE for Economic Modelling).
- [x] Live Elsevier guide-for-authors re-verified 2026-10-13: abstract ≤250,
      1–7 keywords, 3–5 highlights ≤85 characters each, double-anonymized
      review, no mandatory APC — package conforms.
