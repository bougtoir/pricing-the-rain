# Risk Analysis compliance checklist

Source: Wiley Risk Analysis Author Guidelines, Wayback official-page snapshot
2025-08-11 (live page Cloudflare-blocked; see
`docs/RISK_ANALYSIS_FIT_AUDIT.md` and `data/raw/journal_acquisition_ledger.csv`).

| Requirement | Rule | Status |
|---|---|---|
| Article type | Original Research (<7,000 words excl. refs/tables/figures) | Title page + cover letter updated; main text ~4,000 words |
| Double-blind | Title only on page 1; no author names/affiliations in manuscript file | `manuscript_blinded.docx` — title page break, separate `title_page.docx`, bracketed placeholders only |
| Abstract | ≤250 words, page 2, lay-audience readable | Injected count ~200 words; verify in metrics |
| Keywords | 3–5 | 5: performance evaluation; risk adjustment; selective exposure; attribution; reputation |
| Headings | numbered, bold caps (1., 1.1., 1.1.1.) | Main headings caps in template; numbered subheadings |
| Spacing/margins | double-spaced, ≥1 in, 8.5"×11" | builder sets TNR 12 pt, double spacing, 1-in margins |
| References | APA author–date, alphabetical | converted from numeric; builder emits APA list sorted by first author |
| Figures/tables | numbered; inline or separate pages; captions | inline in blinded docx; separate PDF/PNG files in zip; first-citation order retained |
| Data availability | statement encouraged | Data and code availability section cites public repo |
| AI disclosure | COPE/Wiley: describe use in Methods or Acknowledgements | Generative AI disclosure subsection retained with confirmation placeholder |
| Declarations | funding, competing interests, CRediT | bracketed author placeholders retained; never inferred |
| Cover letter | to Risk Analysis editors | rewritten (see manuscript/cover_letter.md) |
| Highlights | not required | dropped from package |
| Submission | Research Exchange (wiley.atyponrex.com/journal/RISA) | author action |
| Screening | iThenticate | note only |
| OA route | hybrid optional | subscription route acceptable; author decision |

## Residual EE-specific items removed
