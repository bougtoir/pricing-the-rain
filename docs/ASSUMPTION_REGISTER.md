# Assumption register

| ID | Assumption | Status and implication |
|---|---|---|
| A1 | Ritual has exactly zero meteorological effect. | Structural invariant: potential rainfall is identical under intervention and no intervention. |
| A2 | Point reanalysis precipitation represents a local rainfall opportunity process. | Suitable for mechanism demonstration, not historical community reconstruction. |
| A3 | A rain day is at least 1 mm in the primary analysis. | Sensitivity analyses use 0.1 and 5 mm. |
| A4 | Apparent success is rain within 1, 3, 7, or 14 days. | Descriptive attribution window, never causal efficacy. |
| A5 | Training-period hazards can be available to a stylized informed provider. | Uses only 1991–2010 data for 2011–2020 pseudo-events; still an informational benchmark. |
| A6 | Economic loss and social utility are calibrated scenarios. | They are not estimates of historical payments or beliefs. |
| A7 | Providers may condition acceptance on noisy baseline-hazard information. | Theoretical strategy, not an empirical claim about historical rainmakers. |
| A8 | Bayesian, recency, and selective-memory observers are stylized. | Used to compare attribution rules, not diagnose real communities. |
| A9 | Eight point locations span major rainfall regimes sufficiently for a mechanism stress test. | They do not establish global representativeness. |
| A10 | Open-Meteo's ERA5 access remains stable for exact reruns. | Raw responses and checksums are retained to preserve the analyzed snapshot; an all-null ERA5-Land response is retained but excluded. |
| A11 | The event occurs before observing event-day rainfall. | Dry spell and 30-day drought use only prior days; success begins on the next day. |
| A12 | The Phase 3 WTP scale is a calibrated scenario. | It demonstrates an attribution-pricing channel and is not evidence about historical prices. |
| A13 | A simulated community has four providers. | This is a transparent device for studying reputation dispersion, not a historical count. |
| A14 | Social utility is positive even under zero rainfall efficacy. | It represents possible coordination/solidarity value and is varied in robustness analysis. |
| A15 | Payments are transfers; provider cost is a resource cost. | Total surplus excludes transfers and includes no causal rainfall benefit. |
| A16 | Display values may be rounded, but manuscript-generation code reads unrounded machine-readable results. | Prevents transcription drift while keeping displays legible. |
| A17 | Bibliographic fields are generated from archived Crossref metadata except for Akong'a (1987), which uses the preserved institutional PDF. | Avoids invented metadata while retaining an important historical source absent from Crossref. |
| A18 | The pinned Python environment and archived raw snapshots define the reproducible computational target. | Numerical CSV/JSON outputs are deterministic under this target; document-container metadata may vary across LibreOffice and Office-library versions. |
| A19 | Completely absent or sparse training duration cells can use a training-period location-month hazard. | Prevents missing prospective-hazard covariates without using evaluation outcomes; the fallback is less state-specific. |
| A20 | Audit-source redistribution requires affirmative permission. | The institutional article and captured journal guide remain in persistent private storage; the public release carries exact acquisition records rather than republishing them. |
