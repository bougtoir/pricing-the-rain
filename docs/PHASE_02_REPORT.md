# Phase 2 report: formal ecological-economic model

The formal model enforces \(R(1)=R(0)\) as a structural invariant and separates:

- natural rainfall and prospective baseline hazard;
- environmental scarcity, economic exposure, and requests;
- provider signals, acceptance, and strategy;
- apparent success and four observer types;
- instrumental rainfall value, belief-mediated WTP, and non-meteorological social utility;
- actuarially fair causal price, WTP, revenue-maximizing price, and welfare-neutral price;
- reputation updating and memory.

The DAG-style framework is generated as SVG by `src/model_diagram.py`. It contains no
causal arrow from pseudo-intervention to rainfall. Historical behavior is not inferred
from the model.
