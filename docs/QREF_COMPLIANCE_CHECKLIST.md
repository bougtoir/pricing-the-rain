# QREF compliance checklist

Live Elsevier Guide for Authors for *The Quarterly Review of Economics and
Finance* (ISSN 1062-9769) re-verified 2026-10-18. QREF uses the standard
Elsevier guide template; items marked [live] were read from the current
guide page, items marked [Elsevier-standard] are from the shared Elsevier
guide sections that QREF's TOC lists verbatim.

- [x] Article type: Research article (theoretical; QREF publishes
      "theoretical, empirical or policy related" work — [live]).
- [x] Double-anonymized peer review ([live]) → separate title page +
      blinded manuscript with title-only first page; all author identity
      fields are bracketed placeholders.
- [x] Title page: article title, article type, author names/affiliations/
      corresponding author/email/telephone/ORCID placeholders + JEL
      classification (D81; D82; D83; D84) — JEL codes appear on all recent
      QREF articles.
- [x] Abstract: single paragraph, 248 words ≤ 250 (enforced by
      tests/final audit; [Elsevier-standard] concise-abstract rule).
- [x] Keywords: 6 supplied (Elsevier allows up to ~7–8; [Elsevier-standard]).
- [x] Highlights: 5 items, ≤85 characters each [Elsevier-standard].
- [x] Manuscript length: no hard QREF cap in the live guide; main text
      ~6,400 words excluding references.
- [x] References: Elsevier name–date (APA-style author–year), alphabetized,
      every entry cited in text; 28 references.
- [x] Math: native OMML equations in DOCX; LaTeX also accepted by journal.
- [x] Figures 1–5 cited in order; Figures S1–S3 in supplement; vector PDF +
      600-dpi PNG + editable PPTX supplied.
- [x] Tables 1–4 cited in order; Tables S1–S10 in supplement; CSV + editable
      DOCX supplied.
- [x] Declarations: funding, competing interests, CRediT, ethics, data/code
      availability, generative-AI disclosure — present with bracketed
      author placeholders [Elsevier-standard sections all listed in guide].
- [x] Data statement: public GitHub repository with frozen outputs,
      acquisition ledgers, and checksums.
- [x] Cover letter: single-author "I", ~1 page, restrained claims.
- [!] **Submission fee: US$150, non-refundable, for new unsolicited
      manuscripts — [live]**. This is a mandatory fee: it must be paid
      before the manuscript is considered. Recorded as author action #9.
      (Optional Gold OA carries a separate APC; subscription publication
      itself has no page charge.)
